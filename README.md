# 📱 Proyecto principal

## Renta Inversor

Aplicación desarrollada con **Flutter y Firebase** para ayudar a inversores en España a organizar sus operaciones y facilitar el cálculo y seguimiento de su fiscalidad.

El proyecto me permite trabajar sobre un producto real, desde la arquitectura y el desarrollo hasta el testing, publicación y mantenimiento.

### Algunas funcionalidades

* Gestión de acciones, ETF, fondos, criptomonedas y otros activos
* Cálculo FIFO de operaciones
* Gestión de ganancias y pérdidas patrimoniales
* Importación de operaciones desde CSV y Excel
* Informes fiscales por ejercicio
* Gestión de distintas divisas
* Sincronización mediante Firebase
* Autenticación de usuarios
* Suscripciones Free / Pro
* Integración con APIs externas para búsqueda e identificación de activos
* Exportación de información e informes
* Persistencia local y funcionamiento offline
* Gestión de errores y monitorización de la aplicación

### Tecnologías

**Flutter · Dart · Firebase Auth · Firestore · Firebase Functions · RevenueCat · REST APIs · Android · Git**

El proyecto está publicado para **Android en Google Play** y continúa evolucionando con nuevas funcionalidades y mejoras.
